03  Lab

Working tools, built to be tried.

Working tools, not screenshots. The first three run entirely in your browser on synthetic data, so nothing is uploaded. The rest are open source on GitHub, with tests and made-up example data.

Try it →

PHI De-identification & Re-identification Risk

Paste a clinical note and every HIPAA Safe Harbor identifier is detected, categorised and redacted — then scored for the re-identification risk that survives. Safe Harbor and Limited Data Set are separate modes, because they retain different things.

45 CFR §164.514  ·  NPI/DEA/VIN/MBI checksums  ·  span resolution  ·  k-anonymity estimate
Try it →

Clinical AI Readiness Assessment

A structured go/no-go for a proposed clinical AI use case, scored across patient safety, regulatory posture, data provenance, bias, workflow fit and governance. A hard blocker overrides the total score — because a high average should never outvote "no human in the loop".

21st Century Cures Act CDS carve-out  ·  IMDRF risk categories  ·  weighted scoring  ·  generated risk register
Try it →

EMR Data Quality Profiler

Profiles an EHR-style dataset for completeness, conformance and plausibility, and rules on whether it is fit to train a model. It flags the dangerous failure specifically: missingness that correlates with a grouping variable rather than occurring at random.

Kahn data-quality framework  ·  non-random missingness  ·  unit-switch detection  ·  ICD-10/CPT conformance
View on GitHub →

raid-log: RAID Log as Code

Keeps a project's risks, assumptions, issues and dependencies in a YAML file next to the code. It validates the register, writes a steering-meeting status report, draws a risk heatmap, and shows what changed since the last meeting.

Python  ·  command line  ·  risk exposure scoring  ·  git-aware diffs
